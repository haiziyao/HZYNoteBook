# 模块依赖与调用链

## 模块职责

| 模块 | 职责 | 主要中间件 |
|---|---|---|
| `kb-gateway` | 统一入口、路由、响应/异常、JWT 透传 | Nacos、Redis Reactive |
| `kb-user-auth` | 登录、用户、权限、JWT | MySQL、Redis、Nacos |
| `kb-common` | DTO、统一响应、异常、AOP、工具、Feign 公共依赖 | RabbitMQ、Redis、JWT |
| `kb-foundation` | 字典、配置、通知、操作日志、WebSocket | MySQL、Redis、RabbitMQ |
| `kb-document` | 文档元数据、正文关联、审核、版本、分类标签 | MySQL、MongoDB、ES、Feign |
| `kb-ai` | RAG、KAG、模型调用、索引重建 | ES、Neo4j、Redis、RabbitMQ |
| `kb-search` | 文档全文搜索、混合搜索 | Elasticsearch |
| `kb-graph` | 图谱查询、实体关系展示/清理 | Neo4j、Redis |
| `kb-file` | 文件上传、解析、对象存储 | MySQL、RustFS/S3、Redis |
| `kb-statistics` | 统计报表、访问/行为统计 | MySQL、Redis |

## 关键调用线路

1. 网关根据 `/api/**` 路由到具体服务，并统一处理下游响应。
2. 文档发布调用 `DocumentReviewServiceImpl`，审核通过后使用 Feign 调用：
   - `RagFeignClient` → `kb-ai /rag/reindex/{docId}`
   - `KAGFeignClient` → `kb-ai /kag/build/{docId}`
   - `SearchIndexFeignClient` → `kb-search /index/document`
3. 审核通知和操作日志通过 RabbitMQ 解耦；`kb-foundation` 消费并落库。
4. 服务地址由 Nacos 注册发现，Feign 配合 LoadBalancer 选择实例。

## 依赖方向原则

业务服务依赖 `kb-common`，不应反向依赖具体业务服务；跨服务使用 HTTP/Feign 或消息，不直接访问其他服务的数据库。
