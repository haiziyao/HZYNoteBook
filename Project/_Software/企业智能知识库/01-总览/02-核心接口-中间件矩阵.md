# 核心接口—中间件矩阵

> 下表记录主线接口。普通 CRUD 只保留接口族；实际对外路径可能由网关增加 `/api/{service}` 前缀。

## 认证与用户

| 接口 | 模块 | 中间件/依赖 | 输入 → 输出 |
|---|---|---|---|
| `POST /auth/login` | `kb-user-auth` | MySQL、Redis、JWT | 用户名/密码 → access token、用户信息 |
| `POST /auth/refresh` | `kb-user-auth` | Redis、JWT | refresh token → 新 token |
| `POST /auth/validate` | `kb-user-auth` | JWT | token → 是否有效/用户摘要 |
| `GET /auth/reviewer-ids` | `kb-user-auth` | MySQL、Nacos/Feign | → 可用审核员 ID 列表 |

示例：

```json
// POST /auth/login
{"username":"alice","password":"***"}
// response（示意）
{"code":200,"data":{"token":"<JWT>","userId":11}}
```

## 文档与审核

| 接口 | 模块 | 关键中间件 | 作用 |
|---|---|---|---|
| `POST /documents` | document | MySQL、MongoDB | 创建元数据并关联正文 |
| `PUT /documents` | document | MySQL、MongoDB、版本 | 更新文档并形成快照/正文 |
| `GET /documents/{id}` | document | MySQL、MongoDB | 查询元数据和正文 |
| `PUT /documents/{id}/publish` | document | MySQL、RabbitMQ、Feign | 发布或进入审核 |
| `POST /review/submit/{id}` | document | MySQL、RabbitMQ、WebSocket | 创建审核任务、通知审核员 |
| `POST /review/tasks/{taskId}/review` | document | MySQL、RabbitMQ、Feign | 通过/驳回，触发结果通知和索引任务 |
| `GET /review/tasks` | document | MySQL | 审核员查询待处理任务 |

审核结果示意：

```json
{"approved":true,"comment":"内容合规"}
→ {"code":200,"data":true}
```

注意：MySQL 中的审核记录有“通过/驳回”结果，但文档本身的状态枚举是草稿、已发布、已归档、待审核四种；驳回不是独立的文档状态，通常会退回草稿。

## RAG / KAG / 搜索

| 接口 | 服务 | 存储/中间件 | 输入 → 输出 |
|---|---|---|---|
| `POST /rag/reindex/{docId}` | `kb-ai` | MongoDB、ES `kb_chunk` | 文档 ID → 任务 ID/状态 |
| `GET /rag/reindex/progress/{taskId}` | `kb-ai` | Redis/ES | 任务 ID → 进度 |
| `POST /rag/search` | `kb-ai` | ES 向量/关键词 | `query, topK` → 文本块列表 |
| `POST /rag/chat` | `kb-ai` | ES、LLM | 问题 → 回答与引用 |
| `POST /kag/build/{docId}` | `kb-ai` | MongoDB、Neo4j | 文档 ID → 构建状态 |
| `POST /kag/search` | `kb-ai` | Neo4j | 问题/实体 → 节点、关系、路径 |
| `POST /kag/chat` | `kb-ai` | Neo4j、LLM | 问题 → 图谱增强回答 |
| `POST /` | `kb-search` | Elasticsearch | 关键词、分页 → 文档搜索页 |
| `POST /advanced` | `kb-search` | Elasticsearch | 多条件过滤 → 高级搜索页 |
| `POST /index/document` | `kb-search` | Elasticsearch | 文档索引 DTO → 成功标志 |

RAG 检索示例：

```json
{"query":"如何配置数据源？","topK":5,"enableRerank":true}
→ {"items":[{"documentId":"10001","content":"...","score":0.91}]}
```

## 配置、通知与日志

| 接口/入口 | 模块 | 中间件 | 作用 |
|---|---|---|---|
| `GET /config/{key}` | foundation | MySQL + Redis Hash | 读取配置 |
| `PUT /config/{key}` | foundation | MySQL + Redis | 修改并同步缓存 |
| `GET /notifications` | foundation | MySQL | 分页查通知 |
| `PUT /notifications/{id}/read` | foundation | MySQL | 标记已读 |
| `GET /notifications/unread-count` | foundation | MySQL/Redis | 未读数量 |
| `@OperationLog` | common AOP | RabbitMQ → MySQL | 记录操作日志 |
| WebSocket endpoint | foundation | WebSocket | 在线实时推送，不保存真源 |

## 分类、标签、评论（简写）

- 分类：`/categories/tree`、`/categories/children/{parentId}`、`/{id}/move`；MySQL + Caffeine，重点是树和循环检测。
- 标签：标签 CRUD、文档绑定/解绑；MySQL，多对多和唯一约束。
- 评论：`POST /comments`、`GET /comments/document/{documentId}`、`/{id}/replies`、`/{id}/like`；MySQL，两级树和防重复点赞。
