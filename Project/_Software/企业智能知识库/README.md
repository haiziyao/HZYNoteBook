## 记录规则

- MySQL 是结构化业务真源；ES、Redis、Neo4j 多数属于派生/缓存/检索数据。
- 记录“模块—接口—中间件—输入输出—失败影响”，普通 CRUD 只记录接口族和特殊约束。
- 配置文件中的密码、Token、密钥不进入笔记。
- 涉及共享环境时只做只读检查，不在笔记中记录真实凭据。
