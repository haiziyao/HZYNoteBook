## 尚硅谷给出的笔记说明

基础篇，尚硅谷网盘资料曾经给过md格式的笔记。

高级篇，尚硅谷网盘只给过PDF版本的笔记，这个PDF版本的笔记，有知识点遗漏，比起课程的知识少一些。后来因为出版mysql书籍，版权的问题。PDF版本的笔记也删除了。

## 这份笔记说明

### 1. 基础篇笔记
这份材料的的基础篇笔记，是从B站评论区一个兄弟那边拿来的。

经过学习核对和课程内容一模一样，没有发现遗漏。

猜测是尚硅谷曾经给过的md格式的笔记，也有可能是那个兄弟自己整理的。

### 2. 高级篇笔记
高级篇笔记没有采用评论区兄弟的，因为他做的笔记，内容缺的厉害，比官方的PDF还要少很多。

<b>高级篇PDF</b>

是官方给的PDF文件。

<b>高级篇笔记</b>

是笔者自己整理的，总体和官方视频版基本一致，修正了一些错误，和补充了一些内容，也改写了一些内容。

笔者的第6章，差别比较大，可以参考别人的笔记。

第三章有配置文件的内容，笔者单独拆了一份配置文件的笔记

第四章有部分Oracle内容，笔者单独拆了一份Oracle的笔记

第十九章末尾，有mysql命令，笔者单独拆了一份mysql命令的笔记
