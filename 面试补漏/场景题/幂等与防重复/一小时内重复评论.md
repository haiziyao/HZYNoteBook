## 二、题目与解答

### 1. 如何实现同一个用户一小时内不能提交重复评论？

答案：先定义重复范围（用户、评论对象、规范化后的内容和一小时窗口），再构造幂等键，例如 `comment:dedup:{userId}:{targetId}:{contentHash}`。使用 Redis `SET key 1 NX EX 3600` 原子抢占，成功后才落库；数据库再用唯一约束兜底。

- 不能先 `GET` 再 `SET`，否则并发下会同时通过。
- Redis 成功但 DB 失败会误拦截，可使用处理中/成功状态、补偿删除或短期重试。
- Redis 故障时要明确降级：严格防重可拒绝请求；允许少量重复则降级到 DB 唯一约束。
- 内容 Hash 前需按业务规范化空白、大小写和 Unicode。
