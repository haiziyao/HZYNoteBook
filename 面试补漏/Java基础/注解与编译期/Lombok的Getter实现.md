## 二、题目与解答

### 1. Lombok 的 `@Getter` 是怎么实现的？

答案：Lombok 通过编译期注解处理参与编译，修改或扩展编译器 AST，注入 getter 方法，最终生成普通的字节码；不是运行时通过反射生成。

流程可以概括为：源码标注注解 → 注解处理器被编译器加载 → AST 注入 `getXxx()`/`isXxx()` → 后续编译阶段写入 `.class`。

- IDE 需要 Lombok 插件或启用注解处理，否则可能出现编辑器误报。
- 运行时看到的 getter 与手写方法没有本质区别。
- JDK/编译器升级时要验证 Lombok 兼容性。
