# 面经学习资料库

本目录用于保存从外部链接、帖子或截图中提取的面经题目。这里记录“别人被问了什么”；经过复习和知识扩展后，再把稳定知识沉淀到 [面试补漏](../面试补漏/README.md)。

## 面经文件格式

每份文件必须按以下顺序组织：

1. 文件标题、来源链接和整理元数据。
2. `## 一、题目清单`：只列问题，不写答案、提示、分析或参考结论。
3. `## 二、题目与答案`：可选。需要答案时，题目文字和编号必须与上半部分完全一致；暂时没有答案时保留该标题并写“待补充”，或省略此节。

补充题必须明确标注“补充追问，非原帖原题”，不能把推测内容伪装成原面经。

## 复习状态元数据

```yaml
review_status: 未复习  # 未复习 / 复习中 / 已复习
last_reviewed:        # YYYY-MM-DD；未复习留空
review_count: 0
```

没有元数据的旧文件默认视为“未复习”。只有在你明确同意后，才更新复习状态。

## 从链接整理面经

你提供链接后，我会提取明确出现的面试题，去除闲聊和重复表述；无法确认的内容标注“待确认”，推测题目单独标注。默认先只整理题目，只有你要求补答案时才补充答案区。
