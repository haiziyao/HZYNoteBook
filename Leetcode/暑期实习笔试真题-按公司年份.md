# 暑期实习笔试真题（按公司 · 按年份）

**用途**：把「别人考了什么」变成「我该刷什么」。相同公司归并，按年份分开放。

**列含义**

- **题目**：笔试原始题名（部分为站点改编名，做法与原型一致）
- **考点**：抽象成算法模型，用于反查自己该补哪块
- **力扣相似题**：可直接拿来练的同型题（链接可点）
- **难度**：按笔试实际体感标注 —— 简单（签到）/ 中等 / 较难 / 困难
- **来源**：见文末「溯源索引」，`onefly` = Zero2Leetcode 真题库，`牛客` = 牛客面经复盘，`CSDN` = 题解专栏

**可信度说明**：标 `*` 的条目来自二手面经聚合（细节可能有个位数偏差），其余为带解析的真题页，可直接核对。遇到存疑，以一手复盘为准。

## 十六、高频结论（从上面这些表里抽出来的）

1. **数位 DP 是大厂分水岭**：阿里 3.25 T3、B 站 4.11 T1、蚂蚁 3.29 T3 都是「二分答案 / 逐位贪心 + 数位 DP」。不会这个模板，直接丢一道 200+ 分的题。
2. **并查集 + 逆序删边**出现三次以上（美团 03.14、美团 2024.03.09、阿里 3.28），是"删边连通"类题的固定解法。
3. **尾随零 = min(因子 2 个数, 因子 5 个数)**：字节 4.19 T3、游酷盛世 3.27 T3 都在考这个结论。
4. **矩阵快速幂 + 轮廓线 DP**（拼多多 5.17 T4）属于"顶级难度"信号，出现即放弃骗分。
5. **贪心 + 二分答案**是最容易拿分的组合：字节 4.19 T1、OPPO Q1，模板题，必须秒。
6. **多源 BFS / 网格 BFS**：蚂蚁 3.26 T2（原题 LC 542）、得物 4.18 T3（原题 LC 407）。
7. **ACM 模式是硬门槛**：字节强制、腾讯为主。只会写 LeetCode 函数体 = 直接 0 分。
