# 日常实习笔试与手撕真题（按公司 · 按年份）

**先讲清楚一件事**：日常实习和暑期实习的考核结构**不一样**。

- 日常实习**多数免笔试**，直接进 1-2 轮技术面；面试就是「项目 + 八股 + 1-2 道手撕」。
- 手撕难度**普遍在 LeetCode Medium 偏下**，以链表、二叉树遍历、滑动窗口、数组为主，**原题命中率极高**。
- 因此这张表的重点不是「笔试真题」，而是**面试现场手撕真题**——把公司名换成「谁在面你」，把题换成「他让你写什么」。

**列含义**

- **题目**：面试官原话 / 面经记录题名
- **考点**：抽象算法模型
- **力扣相似题**：可直接拿来练的同型题
- **难度**：日常实习体感难度
- **来源**：见文末溯源索引
