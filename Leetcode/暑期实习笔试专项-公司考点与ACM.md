# 暑期实习笔试专项 · 公司考点与 ACM

> 隶属 [[算法刷题-4个月计划]]。日常实习常免笔试，**暑期实习的笔试是正式关卡**，难度自成体系，必须单独准备。

## 一、为什么笔试要单独准备

三个反直觉的事实：

1. **笔试难度天花板远超面试手撕。** 面试手撕最高到 LC Hard（如 LC 32），但笔试压轴可以出到「并查集逆序 + 线段树」的组合（美团 2026.03.14 第三题）。这类题在 LeetCode 上属于竞赛档，Hot 100 完全覆盖不到。
2. **笔试考「广度」，面试考「深度」。** 笔试可能一道贪心、一道前缀和、一道图论、一道数学；面试则围绕有限题型反复追问优化。
3. **笔试输在时间分配，不是输在不会。** 多数人的失分点是"第三题想了 40 分钟，第四题没看"。

**笔试达标标准（本计划口径）**：120 分钟内 AC 2 道（至少 1 道中等偏难），或 3 道拿到部分分。

## 二、各公司笔试画像

### 字节跳动（研发岗）

| 项目 | 内容 |
| --- | --- |
| 结构 | 15 道选择题 + 3 道编程题 |
| 时长 | 120 分钟 |
| 平台 | 自有平台（类掘金风格，有代码联想和错误提示） |
| 选择题特点 | **场景题，不是八股**："这段代码输出什么""这个并发问题怎么死锁的"，每道都要在脑子里跑一遍。做完约耗 45 分钟 |
| 编程题梯度 | 第一题模拟（边界极多）、第二题 DP（像背包又像区间 DP）、第三题图论 + 线段树优化 |
| 模式 | **强制 ACM 模式** |
| 出题偏好 | DP + 字符串处理（占比约 45%） |
| 允许本地 IDE | 需询问面试官 |
| 筛人逻辑 | 考"高压下的稳定产出"和"取舍能力"——会做但耗时过长同样被筛 |

**真题样例（2026.03.21）**：T1 子串指纹模拟；T2 字典序转 26 进制；T3 枚举字母 + 行列频次预处理；T4 斜率分组后转化为最小化组合数之和，再用小根堆贪心选增量代价最小的 k 条线。

**真题样例（2026.04.19）**：T1 走廊按钮（固定时长 + 贪心覆盖 + 二分答案）；T2 印章网格（拆解为互不接触的 2×2 块）；T3 尾零字典序（因子 2 的位置分布 + 从左到右贪心）；T4 第二大池化（标准模拟）。

| 项目 | 内容 |
| --- | --- |

| 时长 | 120 分钟（部分 90–120 分钟） |
| 平台 | 牛客网 |

**真题样例（2024 届）**：数字字符串不出现连续相同字符的最少修改次数；网格地图最大金币（移动颜色变化扣费）。

## 三、考点分层（按难度梯度）

> 这是笔试准备的能力阶梯。**后端岗策略：入门 + 简单 + 中等全覆盖，较难挑高频，困难可放弃。**

### 入门档（笔试占比约 4.5%）

语法题、模拟、枚举、栈、队列。

### 简单档（约 25.8%）

数据结构、模拟、贪心、排序、链表、前缀和、差分、位运算、哈希表、二叉树。

### 中等档（约 33.9%）— 主战场

| 类别 | 具体考点 |
| --- | --- |
| 动态规划 | 基础 DP、01 背包、完全背包 |
| 查找 | 二分、双指针 / 滑动窗口 |
| 数据结构 | 堆 / 优先队列、单调栈 / 单调队列 |
| 图论 | 基础建图与图上搜索、并查集、01 最短路、拓扑排序 |
| 数学 | 快速幂、杨辉三角（小组合数）、点乘叉乘、高精度计算、向量 |
| 字符串 | 字符串哈希 |
| 搜索 | DFS、BFS、记忆化搜索 |
| 其他 | 贪心、构造、随机化 |

### 较难档（约 31.2%）— 拉开差距

| 类别 | 具体考点 |
| --- | --- |
| 动态规划 | 概率 DP、状压 DP、数位 DP、树形 DP、多重背包（二进制拆分）、滚动数组优化 |
| 数学 | 扩展欧几里得、卢卡斯定理、中国剩余定理、计算几何、筛、容斥原理、乘法逆元（费马小定理）、欧拉函数 |
| 图论 | 差分约束、二分图匹配（匈牙利）、最小生成树、带权最短路、LCA、连通性（Tarjan） |
| 数据结构 | ST 表、树状数组、线段树（含懒标记）、分块 |
| 字符串 | Z 函数、Manacher、KMP、字典树 |
| 其他 | 三分、莫队、摩尔投票、SG 函数 |

### 困难档（约 4.5%）

树/图论、数据结构的复杂组合、DP 的复杂优化、博弈论、复杂几何、模拟退火、计算机理论（图灵机、NP）。

**后端岗必补的「较难」高频子集**（性价比排序）：

1. 并查集进阶（带权、逆序删边转加边）
2. 树状数组 / 线段树（区间和、区间最值、懒标记入门）
3. 单调栈 / 单调队列
4. 二分答案
5. KMP / Z 函数 / 字典树
6. 拓扑排序 + 最短路（Dijkstra）
7. 概率 DP / 状压 DP 入门

## 四、Java ACM 模式速查

### 4.1 Main 类固定格式

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt(), b = in.nextInt();
        System.out.println(a + b);
    }
}
```

> `Main` 类名和格式不能改，否则运行时报错。华为等平台只给 main 函数，包要自己 import。

### 4.2 五种常见输入形式

```java
// 形式 A：多组 + EOF
while (in.hasNextInt()) {
    int a = in.nextInt(), b = in.nextInt();
    System.out.println(a + b);
}

// 形式 A2：多组 + 零尾（a==0 && b==0 结束）
while (in.hasNextInt()) {
    int a = in.nextInt(), b = in.nextInt();
    if (a == 0 && b == 0) break;
    System.out.println(a + b);
}

// 形式 B：T 组
int T = in.nextInt();
while (T-- > 0) {
    int a = in.nextInt(), b = in.nextInt();
    System.out.println(a + b);
}

// 形式 C：字符串（注意 nextInt 后要吃掉换行）
int len = in.nextInt();
in.nextLine();               // 关键：吃掉上一行残留的换行符
String str = in.nextLine();

// 形式 D：逗号分隔数组
int n = Integer.parseInt(in.nextLine().trim());
String[] parts = in.nextLine().split(",");
int[] nums = new int[n];
for (int i = 0; i < n; i++) nums[i] = Integer.parseInt(parts[i].trim());
```

### 4.3 大数据量下的快速 IO（防 TLE）

```java
import java.io.*;
import java.util.*;

public class Main {
    static StreamTokenizer sc = new StreamTokenizer(
            new BufferedReader(new InputStreamReader(System.in)));
    static PrintWriter out = new PrintWriter(System.out);

    static int nextInt() throws IOException { sc.nextToken(); return (int) sc.nval; }
    static long nextLong() throws IOException { sc.nextToken(); return (long) sc.nval; }

    public static void main(String[] args) throws IOException {
        int n = nextInt();
        // ... 计算
        out.println(n);
        out.flush();          // 必须 flush
    }
}
```

### 4.4 常用输出格式化

```java
System.out.println(String.format("%.3f", value));   // 保留 3 位小数（自动补 0）
System.out.println((long) a * b);                   // 溢出处强制转 long
BigInteger x = new BigInteger(s1).add(new BigInteger(s2));  // 大数运算
```

### 4.5 五个必踩的坑

| 坑 | 说明 |
| --- | --- |
| `nextInt()` 后接 `nextLine()` | 会读到残留换行，必须中间加一个 `nextLine()` |
| 多组数据未重置容器 | 每组数据都要重新初始化集合 / 数组 |
| 未处理 `NumberFormatException` | 一旦抛出整个程序崩溃，算法正确也零分 |
| 输出未 flush | 用 `PrintWriter` 必须 `flush()` |
| 整型溢出 | `int * int` 超范围，提前转 `long` |

### 4.6 平台差异

| 平台 | 模式 | 特点 |
| --- | --- | --- |
| 牛客 | ACM / 核心代码混用 | 双机位；有 OJ 输入输出专项练习场 |
| 赛码 | ACM | 代码页为空，有输入输出提示 |
| 字节自有 | 强制 ACM | 有代码联想和错误提示 |
| 华为 | ACM | Scanner 要自己写，部分包自己引 |

> 练习入口：牛客「OJ 在线编程输入输出练习场」——进陌生平台先写一遍 A+B 热身。

## 五、笔试策略

### 5.1 时间分配（120 分钟模板）

| 阶段 | 时长 | 动作 |
| --- | --- | --- |
| 扫卷 | 2 分钟 | 通读全部题目，标记难度，定做题顺序 |
| 选择题 | ≤ 35 分钟 | 不确定的立刻标记跳过，不要纠缠 |
| 编程题 ×3 | 每题 ≤ 25 分钟 | 从最有把握的开始 |
| 收尾 | 15 分钟 | 回补标记题 + 检查输入输出格式 |

### 5.2 三条纪律

1. **先易后难，不按题号顺序做。** 先建立信心，也保证把该拿的分拿到。
2. **15 分钟无思路就跳。** 字节的筛人逻辑是"会做但耗时过长"同样被筛。
3. **部分分也是分。** 暴力解、特判、伪代码都能拿分，不要空着。

### 5.3 提分细节

- **腾讯特别看代码规范**：命名、注释、异常处理、缩进，留 5–10 分钟"格式化代码"。
- **写完主动分析复杂度**，面试官 / 判题系统都吃这一套。
- **笔试后必复盘**：牛客上搜当次题目，看别人题解——大厂出题高度相似，每次笔试都是下次的弹药。
