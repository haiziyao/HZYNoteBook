# 算法刷题 4 个月计划（2026-10-03 → 2027-02-07）

> 配套文件：[[暑期实习笔试专项-公司考点与ACM]]（笔试公司地图、考点分层、Java ACM 模板）

## 一、先把「暑期实习」和「日常实习」的区别说清楚

这是整份计划的立论基础。两者不是难度差一点，而是**考核结构不同**。

| 维度 | 日常实习 | 暑期实习 |
| --- | --- | --- |
| 定位 | 来了就能干活 | **转正考核**，部门 leader 原话是"按正式员工标准来面" |
| 笔试 | 常免笔试，或走个流程 | **正式关卡**：AI 测评 + 计算机基础选择题 + 算法编程题，难度高 |
| 轮次 | 1–2 面 | 字节 3 面 + HR、阿里 3–4 面（含交叉面）、美团 2 面 |
| 考察深度 | 项目能讲清即可 | 项目追问"为什么不用别的方案"、八股要讲到原理层 |
| 时间 | 随时可投 | 固定窗口，2–3 月笔试面试高峰，招满即止 |
| 算法定位 | 90% 是 Hot 100 原题/改编 | **手撕 + 笔试双线**，笔试有独立难度体系 |

**结论：暑期实习要打两条战线。**

- **笔试线**：考的是「在 120 分钟内稳定拿下中高难度题」——这是日常实习几乎不会遇到的。
- **面试线**：考的是「25 分钟内 bug-free 手撕 + 扛住追问」。

两条线的知识点有重叠，但**能力要求不同**：笔试要广（贪心、前缀和、并查集、图论、二分答案都能出），面试要深（有限题型的多种解法和优化）。本计划把两条线并行推进。

## 四、每周固定节奏

| 时段 | 内容 |
| --- | --- |
| 工作日 | 1 道新题（限时 30 分钟）+ 2 道旧题复习；记录「起手模型 + 边界」 |
| 周末 | 专题攻坚 3–4 小时；**W7 起每周 1 次 ACM 模式限时训练** |
| 周日 | 复盘错题本；更新 `Hot - 100.md` 跟踪表 |
| 每月末 | 1 次全真笔试模拟（2 小时，严格计时） |

**单题训练法**

1. 独立想 15–20 分钟，无思路看题解——不要死磕。
2. 合上题解默写，一次通过主边界用例。
3. 记「起手算法 + 核心不变量 + 最易错的边界」，不抄代码。
4. 隔天再手写一遍；隔周第三次。

**刷题三遍法**：按标签（建立条件反射）→ 乱序（面试不会告诉你标签）→ 限时默写（变成肌肉记忆）。

## 五、阶段详解

### 阶段 0｜摸底（W1，10/03–10/11）

1. **诊断题 10 道**，闭卷限时 30 分钟/题，覆盖滑窗 / 链表 / DP / 二叉树 / 堆 / 贪心 / 图论各至少 1 道。
2. **全真笔试 1 套**（选一套字节或美团真题，2 小时严格计时）——目的是感受强度，不是刷分。
3. **清欠账**：`Hot-100/Day-1.md` 里状态为"待复习"的题（两数之和、最长连续序列、三数之和、接雨水、LC 3 等）重写一遍。
4. 建立错题本，字段：题目 / 错误原因 / 正确思路 / 同类题。

### 阶段 1｜筑基 + Hot 100 一刷（W2–W6，10/12–11/15）

按专题推进，每周 1–2 个专题：

| 周 | 专题 | 重点 |
| --- | --- | --- |
| W2 | 哈希 / 数组 / 双指针 | 前缀和、去重边界 |
| W3 | 滑动窗口 / 子串 / 矩阵 | 窗口收缩条件 |
| W4 | 链表 | 反转系列一起练：LC 206 → LC 92 → LC 25 |
| W5 | 二叉树 / 图 | LC 102 / 103 / 199 共用 BFS 框架；LC 200 + 695 成组 |
| W6 | DP + 堆 + 回溯 + 贪心 | 按爬楼梯 → 打家劫舍 → 股票 → LIS → 零钱兑换 → 编辑距离递进；贪心同步补（卷覆盖率 87%） |

### 阶段 2｜乱序二刷 + 笔试启动（W7–W11，11/16–12/20）

- **乱序二刷 Hot 100**：打乱标签顺序，强制判断题型。
- **补经典 150 差异题**（区间、位运算、图论进阶、二分答案等 Hot 100 未覆盖部分）。
- **笔试专项启动**（本阶段重点）：
  - W7：ACM 模式 Java 输入输出模板（见配套文件），跑通牛客 OJ 输入输出专项 10 题。
  - W8：贪心 + 排序 + 前缀和 + 差分。
  - W9：二分（含二分答案）+ 双指针 + 滑动窗口 + 单调栈 / 单调队列。
  - W10：图论基础（建图、BFS/DFS、拓扑排序、并查集、01 最短路）。
  - W11：DP 进阶（背包、区间 DP、状态机 DP、线性 DP 优化）+ 字符串（KMP / 字符串哈希）。
- **交付物**：一份自己的模板笔记（滑动窗口框架、回溯三部曲、DP 五步、二分边界、并查集、单调栈），沉淀到 `面试补漏/算法/`。

### 阶段 3｜三刷 + 双线专项（W12–W16，12/21–01/24）

- **面试线 · 限时默写**：P0 榜每道题 25 分钟内一次写对。
- **面试线 · CodeTop 公司榜**：选定 2 家目标公司，刷该公司 TOP 50。
- **面试线 · 非 LC 专项**：
  - LC 912 手写快排 + 归并（腾讯 85 次）
  - LRU（双向链表 + 哈希表，禁用现成容器）+ 线程安全版追问
  - 大数加法 / 乘法 / 计算器
  - Rand7 → Rand10（拒绝采样）
  - 前缀树 Trie、用栈实现队列
  - 场景题：敏感词过滤、等概率抽样、消消乐
- **笔试线 · 较难档攻克**：
  - 树状数组、线段树（区间和 / 区间最值 / 懒标记入门）
  - 并查集进阶（带权、逆序删边转加边）
  - 二分答案 + 贪心判定
  - 概率 DP、状压 DP 入门
  - KMP / Z 函数 / Manacher、字典树
- **每周**：1 套全真笔试（2 小时）+ 1 次模拟面试（30 分钟）。

### 阶段 4｜冲刺模拟（W17–W18，01/25–02/07）

- **全真笔试**：每周至少 2 套，覆盖字节 / 腾讯 / 美团 / 百度。
- **模拟面试**：练「先说思路 → 再写代码 → 主动分析复杂度 → 回答追问」的完整表达。
- **错题清零**：只做错题和 P0 榜，不开新题。
- **并行事项**：2 月同步改简历、准备项目讲述（算法只是其中一环，项目深度和八股同样决定结果）。

## 六、题量与验收

| 类别 | 目标题量（含重复） |
| --- | --- |
| Hot 100 | 3 遍 = 300 题次 |
| 经典 150 差异题 | 60–80 题 |
| 公司专项（CodeTop TOP 50 × 2 家） | 100 题次 |
| 笔试专项（贪心 / 图论 / 二分答案 / 数据结构） | 120–150 题 |
| **合计** | **约 600 题次，去重约 350–400 题** |

**一道题算「掌握」的标准：**

1. 不看答案能讲清起手模型与选择理由；
2. 一次手写通过主要边界用例；
3. 能说出时间 / 空间复杂度；
4. 面对追问能给出替代解法（LC 215 → 快选 + 堆；LC 300 → DP + 贪心二分）。

**笔试达标标准**：120 分钟内 AC 2 道（其中至少 1 道中等偏难），或 3 道拿到部分分。
