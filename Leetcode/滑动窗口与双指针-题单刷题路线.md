## 四、只背 3 个模板，别背题

```
# ① 定长滑窗
for i in range(n):
    加入 a[i]
    if i >= k - 1:
        更新答案
        移除 a[i - k + 1]

# ② 不定长 · 越短越合法（通常是求最长 / 最大）
left = 0
for right in range(n):
    加入 a[right]
    while 窗口不合法:
        移出 a[left]; left += 1
    更新答案(用 right - left + 1)

# ③ 不定长 · 越长越合法（通常是求子数组个数）
left = 0
for right in range(n):
    加入 a[right]
    while 窗口满足要求:
        移出 a[left]; left += 1
    ans += left          # ← 关注 left 的合法性，不是 right

# ④ 恰好型 = 两个「至少」相减
ans = f(k) - f(k + 1)     # 封装成函数 f，只需写一份滑窗
```

**验收标准**

1. 每题三遍：① 读懂【套路】题解 → ② 关掉题解盲写 → ③ 隔 3 天重写一次（第三遍才算数）。
2. **掐表**：中等题 20 min、困难题 25 min。超时立刻看题解并标二刷，不要死磕。
3. 收尾必须回答作者留的思考题：**滑动窗口和双指针的区别是什么？**
   （参考答法：滑动窗口本质是**同向双指针**的特例，维护的是一个可变长的区间，判断依据是「窗口整体是否合法」；而双指针更关注两个指针各自的位置关系 —— 相向、同向、背向，判断依据是「两个指针所指元素的关系」。）
4. 72 小时复习节点：第一批完成后隔 3 天，随机抽 8 道重写模板题。
