### 这个表说明什么

**你说刷过三遍 Hot 100，但跟踪表里能确认到 3 次的只有「链表」和「二叉树」两节**；哈希 / 双指针 / 滑窗 / 普通数组 / 矩阵是 1 次；而**贪心、动态规划、多维动态规划、技巧这四块基本是空白**。

一个可能的解释：0 代表「没有记录」而不是「没做过」——跟踪表自己也注明「不能确认已完整手写的题目记为 0，不猜次数」，而且 `Hot-100/` 下只有 `Day-1.md` 一份。**如果你其实做过，告诉我一声我改表。**

但无论哪种情况，这 34 道都该作为「必须能不看答案盲写」的清单过一遍，因为**它们正好压在真题权重最高的两块上**：

- 贪心 3 道 + DP 8 道 + 多维 DP 5 道 = **16 道，占缺口的 47%**，对应真题权重 **27.2%**
- 而「技巧」5 道（位运算 / 荷兰国旗 / 下一个排列 / Floyd 找环）是**笔试里性价比最高的送分题**，居然全空

> **所以：不要现在就去开 12 篇题单。先花 2–3 周把 Hot 100 这 34 道补干净。**
> 理由很简单——Hot 100 是「必须能盲写」的底线题库，而你缺的正好是最值钱的那部分。带着空白的 DP 去刷 DP 题单，只会更痛苦。

## 二、为什么**不**按灵神的新手村顺序走

灵神给的核心路线是：

```
编程入门 → 滑动窗口 → 二分 → 数据结构 → 链表树回溯(二叉树DFS)
→ 网格图 → 链表树回溯(回溯) → 动态规划
```

**那是给萌新的"建立算法直觉"路径**——先练递归，再用网格图和回溯巩固递归，最后才上 DP。逻辑自洽，但**不适合你**：

1. **你的约束不是"学会"，是"3 月开闸前命中考频"。** 萌新路径的终点才是 DP，但**贪心（真题 15.2%）在路径里排得更靠后**。
2. **你不是零基础。** 链表、二叉树、双指针、滑窗、BFS 你已经有底子，萌新路径前 40% 对你边际收益很低。
3. **你有真题库。** 不需要靠"通用学习顺序"猜权重，可以直接按命中率排。

> 排序依据改为**真题考频 + 你的实测缺口**，不是教学逻辑。灵神的方法论（按专题刷、螺旋上升、第一题当例题）照单全收，**只换顺序**。

## 五、笔试形态训练（Hot 100 给不了的四种能力）

**这是「通过笔试」和「刷题多」之间的真正差距。**

### 1. ACM 模式：自己写输入输出

- **字节强制 ACM 模式**；腾讯以 ACM 为主；百度用赛码。
- Java 注意：数据量大时 `Scanner` 会 TLE，改用 `BufferedReader` + `StringTokenizer`。
- **做法**：每刷完一批题，挑 2–3 道用 ACM 模式重写一遍（`Leetcode` 的「核心代码模式」和笔试不是一回事）。

### 2. 数据范围 → 复杂度 → 算法 的快速判断

拿到题先看数据范围，反推允许的复杂度，再选算法：

| 数据范围 | 允许复杂度 | 选择 |
|---|---|---|
| n ≤ 20 | O(2ⁿ) | 状压 DP / 回溯 / 暴力搜索 |
| n ≤ 40 | O(2^(n/2)) | 折半枚举 |
| n ≤ 500 | O(n³) | Floyd / 区间 DP |
| n ≤ 5000 | O(n²) | 二维 DP / 背包 |
| n ≤ 10⁵–10⁶ | O(n log n) / O(n) | 线性 DP / 滑窗 / 二分 / 排序 |
| n ≤ 10⁹ | O(log n) / O(1) | 二分 / 快速幂 / 数学公式 |

> 注：常数因子有影响，哈希表比数组慢；Python 吞吐量约为 C++ 的 1/10。

### 3. 120 分钟 3–4 题的节奏

- **先通读全部题目再动笔**，不要按顺序死磕第一题。
- 时间分配参考：T1 15 min（签到必拿）→ T2 25 min → T3 40 min → 剩余时间给 T4。
- **每题先写暴力解**：部分分机制真实存在，暴力解可能是 30–50% 的分。能写出暴力解也说明你读懂了题。

### 4. 模拟题的实现能力（真题 14.6%，题单零覆盖）

- 从《大厂笔试真题库》Excel 里筛「考点」含**模拟**的行，逐题实现。
- 每两周做一次**随机训练**（灵神方法 B）：<https://huxulm.github.io/lc-rating/>，设置里关闭算法标签，难度锁 1500–1900。
  - 好处：比赛和笔试不会告诉你题目类型，随机训练练的是**判断用什么算法**的能力。
  - 缺点：知识点零散。所以只能作为检验，不能替代专题训练。

**验收标准**：3 月开闸前，能在 120 分钟内稳定 AC 3 题（含至少 1 道中等偏难）。

## 六、难度分阈值（这里没有用灵神的数字）

**灵神原文的阈值读不到。** 总纲里有 5 处「完成难度分 ? 的题目」，页面把 `<1400` 这类写法当 HTML 标签吞掉了，两次抓取都只拿到空白。第三方转载只印证了一句「**动态规划至少刷 100 题才算入门**」。

所以阈值由真题库反推：

| 轮次 | 难度分区间 | 说明 |
|---|---|---|
| 阶段 A–B | **≤ 1600** | 单一知识点，建立模板 |
| 阶段 C | **1600 – 2000** | 多知识点交叉，笔试「中等 / 较难」档 |
| 冲刺 | 2000+ 单点补 | 只在已知公司考过时碰（如美团 T3 段） |

配一个工具：装 **LeetCodeRating** 插件，可在题单里直接显示难度分、自动标记做过的题。

## 七、四条执行纪律（来自总纲，照抄）

1. **按专题刷，不随机刷。** 一个套路解决一批题。
2. **螺旋上升。** 先把各篇基础题刷一遍，再回头刷更难的——低难度题只考一个知识点，高难度题考多个。
3. **每篇的第一道题当例题。** 精读它的题解（灵神题解通常含理论讲解），其余题当配套练习。
4. **不要死磕。** 想不出来 10 分钟到数小时都可以看题解；看完觉得「妙」就是学到了。真看不懂的直接收藏跳过，过段时间再来。

**外加三条自查（评论区高赞，我认同）**：
- 不要一上来就求最优解：先想暴力解 → 找瓶颈 → 针对瓶颈优化。
- 不追「击败 100%」，真正的能力是**能自己分析时空复杂度**。
- 不写一行流。代码简洁去掉冗余就够了。
