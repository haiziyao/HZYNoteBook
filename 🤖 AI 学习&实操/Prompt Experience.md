#### Agent 前沿技术

``` md
你作为一个Agent的资深研究员,对前沿技术有着十分的把握,请你评价我写的文章,对文章进行补充和润色,之后在合适的位置提出一些插图建议,并给出我对应的提示词,供我生成图片
```

```
明亮卡通插画风格，橙色、珊瑚橙、奶油白、青绿色、少量柔和浅蓝点缀，温暖清爽，有工程感但不做蓝色科技风。画面干净，形状圆润，轻微 3D 纸雕感或扁平矢量感，适合技术长文配图。不要深蓝科技风，不要赛博朋克，不要黑色霓虹背景，不要代码雨，不要真实品牌 logo，不要复杂文字，不要水印。
```
